## ⚠️ Read this first — how to use this book honestly

Two kinds of content live here:

- **📌 Confirmed structure** — round names, question counts, time limits, topics, languages, and
  evaluation criteria for the Technical Module, Debugging Assessment, and AI-Assisted Coding
  Assessment. This comes directly from Capgemini's own official slides.
- **🔮 Practice content** — every question/problem in Chapters 1–4 is a predicted, standard
  practice item built to match those confirmed topics — **not leaked real exam questions**.
  Chapter 5 (HR/Behavioral) is a bonus chapter not shown in the original slides at all, included
  because most fresher hiring pipelines include a human round like this.

Confidence built on *"I understand why this is the answer"* transfers to the real exam.
Confidence built on *"I memorized these exact 130 questions"* does not. Read this book to learn
the reasoning, not just the answer key.

## 🎓 How to run a mock session with students

1. **Chapters 1 + 2 (MCQs):** 22-23 minutes each, no notes, real exam pressure. Afterward, review
   the ❌ "why wrong" explanations together — that's where the real learning happens.
2. **Chapter 3 (Debugging):** Have students attempt each of the 8 problems **blind, on a 15-20 min
   timer**, before reading the explanation — narrating Review→Identify→Fix→Validate out loud.
3. **Chapter 4 (AI-Assisted Coding):** Give access to an AI assistant, grade on **how** they
   prompted using the rubric table inside the chapter — not just whether the code worked.
4. **Chapter 5 (HR/Behavioral):** Run as mock interviews — one student asks, one answers, then
   swap. Push for specific real examples, not memorized scripts.
5. **Chapter 6 (Live Coding Scenarios):** Give students a real buggy MERN component (or one with a
   feature request) and have them run the prompts themselves — then require them to explain each
   flagged bug or step *in their own words*, with no AI help, before moving on. This is the step
   that actually determines whether the round goes well, not the prompt alone.
